A fix for a crash in 1.0.0, on both the PAL and USA discs.

**Update:** open the launcher and press **Update**, or download **AgentUnderFireLauncher.exe** below if you are new. Your saves and settings are kept.

## Fixed

- **A crash on foot when the game draws certain models.** 1.0.0's fix for an older crash in the game's own code could itself cause a crash
  whenever a model with exactly eight parts was drawn (reported on the USA disc). Both crashes are fixed.

Everything else is as in 1.0.0. Please report anything you find, with `AgentUnderFire\play\logs\auf.log` and any `.dmp` file beside the game.
